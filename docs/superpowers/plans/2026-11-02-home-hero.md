# Home Hero and Click-Gated Intro — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the auto-playing home intro with a floating-logo cover that waits for a click, then performs the prototype entry into a centred home hero whose transient paragraph reveals and fades.

**Architecture:** `homePage` gains an optional `heroBody`. The header brand is hidden on home; a new `HeroBrand` renders the visible h1 lockup. `HomeIntro` is a full-screen button rendered through a named slot outside `.page`; while pending/moving `.page` is `visibility: hidden`, so only the button is focusable. `intro.js` waits for a click, then runs the WAAPI timeline and hands the lockup to the real hero.

**Tech Stack:** Astro 7, native View Transitions, Web Animations API, CSS custom properties, Sanity, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-02-home-hero-design.md`

## Global Constraints

- Astro 7, `output: 'static'`; no framework islands; vanilla JS only.
- Client JS under 30 KB total; the intro module stays ≤ 6 KB source.
- WCAG 2.2 AA; `prefers-reduced-motion: reduce` and no-JS show the hero immediately.
- Tokens: `--ink #000`, `--paper #fff`, `--muted-text #6e6e6e`, `--graphite #3e3e3e`, `--control #d9d9d9`; 1 px rules; no shadows or gradients.
- English at `/`, Greek at `/el`; 320 px must not scroll horizontally.
- Full-document-load only; internal navigation to home must not replay the cover.
- Cover must never block the site if `intro.js` fails: the 4 s guard reveals the hero.

## Review Focus

1. **The cover blocks the site** when `intro.js` fails, when the visitor uses a keyboard, or when the visitor cannot click. Tests in Task 2 (failed module, keyboard, no-JS).
2. **Focus or AT reaches invisible page content** while the cover is up. Tests in Task 2 (cover axe, hidden h1/nav).
3. **The hand-off jumps at 320 px** because the overlay and hero wrap differently. Test in Task 2 (rect comparison).
4. **The paragraph sticks or the sequence stalls** when `heroBody` is missing or the visitor skips. Tests in Task 2 (paragraph visible then hidden; Escape).
5. **The header brand appears twice or disappears on other pages.** Test in Task 2 (home vs about).

export async function enterHome(page: Page): Promise<void> {
  const intro = page.locator('[data-home-intro]')

      dy: Math.abs(a.top - b.top),
      dw: Math.abs(a.width - b.width),
      dh: Math.abs(a.height - b.height),

- [ ] **Step 5: Implement the cover and timeline**

`HomeIntro.astro`:

```astro
<div class="intro" data-home-intro>
  <button class="intro__enter" type="button" aria-label={t('home.enter', lang)}>
    <span class="intro__stage" data-hero-overlay>
      <HeroBrand as="div" title={title} lang={lang} />
      <img class="intro__ghost" data-intro-ghost src="/mark.png" alt="" width="158" height="192" />
      {body && <p class="intro__body" data-hero-intro-body aria-hidden="true">{body}</p>}
    </span>
  </button>
</div>
<script is:inline src="/scripts/intro.js" defer></script>
```

CSS: `.intro` fixed white overlay, z-index 20, hidden unless `data-intro` is pending/moving/handoff/revealing; `.intro__enter` full size, transparent, border 0; `.intro__stage` fixed, transform-origin top left, opacity 1; `.hero-brand__lead/.tail`, `.intro__body`, `.intro__ghost` use `visibility: hidden` (not opacity) while pending so axe does not evaluate hidden contrast; `.intro__body` is absolutely positioned beside/below the wordmark so it never changes the stage box; float keyframes on `.intro .hero-brand__mark` only while pending; reduced motion disables the float and hides the intro.

`intro.js`:

1. On load, clear `window.__cpIntroTimeout`; return unless `[data-home-intro]` exists, `data-intro === 'pending'`, and `data-intro-ran` is unset.
2. Install the button click and `keydown` listeners; set `data-intro-ran`. The first click starts; a later click or Escape skips.
3. Start: set `moving`; set the stage width to the real `[data-hero-lockup]` rendered width (not its parent) so the overlay and hero wrap identically; position the stage so the overlay mark is centred at 1×; measure the real lockup rect. The paragraph is absolutely positioned so it never changes the stage height.
4. Animate:
   - ghost: translateX ~120 px + fade, 300 ms;
   - wordmark lead/tail: fade/translate in, 500 ms;
   - if `body`: paragraph reveal 600–2600 ms, hold to 4100 ms, fade off by 6100 ms **and set `visibility: hidden` when the fade ends** (so the test and axe see it as gone); if empty, jump to hand-off at 600 ms;
   - 6100–6400 ms: stage transforms to the real hero lockup rect (translate; scale = real.width / stage.width);
   - set `handoff`; set `revealing`; fade overlay 300 ms; after cleanup remove overlay, delete `data-intro`, focus `main`.
5. Skip: finish animations, jump to revealing, remove the overlay, focus `main`.
6. On missing elements or error: reveal the page immediately.
7. Do not touch `sessionStorage`.
