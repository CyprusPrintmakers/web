# Motion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the Figma prototype's home entry sequence and a ~300 ms page crossfade to the existing bilingual Astro site, without changing layout, content, or the interactions already shipped.

**Architecture:** Astro's `ClientRouter` handles internal navigation and the page dissolve. A small vanilla module (`public/scripts/intro.js`) plays a one-shot overlay timeline with the Web Animations API, then hands the lockup to the real header brand. Motion is progressive enhancement: it never runs with JS off, under `prefers-reduced-motion`, or on client-side arrivals at home. Filter and form scripts move to `astro:page-load` initialisers so they survive client navigation.

**Tech Stack:** Astro 7 (`output: 'static'`, `@astrojs/vercel`), native View Transitions, Web Animations API, CSS custom properties, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-02-motion-design.md`

## Global Constraints

- Astro 7, `output: 'static'`; SSR only for `/api/*` and `/preview/*`.
- Node 22.x on Vercel; npm only; no pnpm or bun.
- No Tailwind, no framework islands; vanilla JS only.
- Client JS under 30 KB total (current public scripts ≈ 4.4 KB; intro target ≤ 3 KB).
- WCAG 2.2 AA; `prefers-reduced-motion: reduce` disables all new motion; no focus traps.
- Tokens: `--ink #000`, `--paper #fff`, `--muted #b3b3b3` (decorative only), `--muted-text #6e6e6e`, `--graphite #3e3e3e`, `--control #d9d9d9`; 1 px rules; pill radius 34 px; no shadows or gradients.
- English at `/`, Greek at `/el/…`; Greek must fit at 320 px with no horizontal scroll.
- Every page keeps `lang`, canonicals, sitemap and staging guards unchanged.
- Run npm/Playwright commands from `site/`; run git commands from the repo root.

## Review Focus

1. **A filter or form is dead after the first client-side navigation.** Every internal link becomes a router navigation; scripts keyed by `src` do not re-run. Tests in Task 3.
2. **The intro flashes or replays when home is reached through the router.** A head script runs after a swap too. Tests in Task 4 (client arrival, repeat visit).
3. **The hand-off double-exposes or jumps the wordmark, especially at 320 px / three-line Greek.** Tests in Task 4 (320 px overflow, hand-off).
4. **Reduced-motion or no-JS users still get the overlay or a dissolve.** Tests in Tasks 2 and 4.
5. **Focus or scroll lands in the wrong place after navigation.** Tests in Task 2.

- [ ] **Step 3: Add the head gate**

In `BaseLayout.astro` props add `homeIntro = false`. In `<head>`, **before** any home-specific script, always render the document counter:

```html
<script is:inline>window.__cpDocs = (window.__cpDocs ?? 0) + 1;</script>
```

When `homeIntro`, render after it:

```html
<script is:inline>
  (() => {
    try {
      if (window.__cpDocs !== 1) return
      if (matchMedia('(prefers-reduced-motion: reduce)').matches) return
      if (sessionStorage.getItem('cp:intro')) return
      document.documentElement.dataset.intro = 'pending'
      window.__cpIntroTimeout = setTimeout(() => {
        if (document.documentElement.dataset.intro === 'pending') {
          delete document.documentElement.dataset.intro
        }
      }, 8000)
    } catch {}
  })()
</script>
```

`window.__cpDocs` makes the intro full-document-load only: Astro also executes head scripts after a client swap, and the counter is then 2 or more.

- [ ] **Step 5: Implement `intro.js`**

The module:

1. Returns unless `[data-home-intro]` exists, `documentElement.dataset.intro === 'pending'`, and `data-intro-ran` is unset.
2. Installs the Escape/click/any-key skip listeners first, then sets `data-intro-ran` (the attribute therefore guarantees Escape works), then treats a reduced-motion match as skip.
3. Measures the real `header .brand` and the clone (`.intro__stage .brand`) with `getBoundingClientRect()`.
4. Computes `startScale = Math.max(1, Math.min(1.6, (innerWidth - 48) / clone.width, (innerHeight - 48) / clone.height))`; positions `.intro__stage` at the centred scaled rect (`left = clone.left - clone.width * (startScale - 1) / 2`, same for top, `transform: scale(startScale)`) and sets its opacity to 1.
5. Positions `.intro__ghost` over the clone's `.brand__mark` **relative to the stage** (`left = markRect.left - stageRect.left`, same for top/width/height) before applying the stage scale, then sets its opacity to 1.
6. Runs the timeline with `element.animate()`:
   - ghost: `translateX(120px)` + opacity 1→0, 320 ms;
   - `[data-brand-line]` spans: from `opacity: 0; translateX(∓24px)` to identity, 600 ms, 60 ms stagger;
   - stage: from `scale(startScale)` to `translate(real.left - stageLeft, real.top - stageTop) scale(real.width / clone.width)`, 500 ms starting at 400 ms.
7. At the end of the move sets `data-intro = 'handoff'`, then animates the overlay opacity 1→0 over 300 ms, sets `data-intro = 'revealing'`, and after 400 ms removes the overlay, deletes `data-intro`, clears `__cpIntroTimeout`, and writes `sessionStorage['cp:intro'] = '1'`.
8. Skips on `Escape`, click, or any key: `finish()` every animation, jump to the handoff/reveal state, clean up.
9. On any missing element or thrown error, cleans up immediately (no intro, no stuck overlay).

Use `fill: 'both'` and the `--ease-out-expo` curve for movement; `ease-out` for fades. Do not animate layout properties.

Reference frames for visual tuning: `docs/superpowers/specs/motion-reference/`.
